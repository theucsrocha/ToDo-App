ToDo List App 🚀

Aplicação de gerenciamento de tarefas desenvolvida para o desafio da ZG Solutions. O projeto agora é Full Stack, com separação clara entre as lógica de servidor e interface [cite: 2026-03-05].
🛠️ Estrutura do Projeto

    backend/: Lógica em Java desenvolvida no IntelliJ [cite: 2026-03-05].

    frontend/: Interface responsiva em HTML, CSS e JavaScript feita no VS Code.

✨ Novas Features (Desafio Sandubinha)

    Persistência Local: As tarefas são salvas no localStorage do navegador e não somem ao atualizar a página.

    Status em Massa: Opção de selecionar múltiplas tarefas via checkbox e alterar o status de todas simultaneamente.

    CRUD Completo: Adicionar, listar, atualizar e remover tarefas com facilidade.
